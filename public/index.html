邮箱验证码读取

仅用于你自己拥有的账号，凭证只与微软官方 Graph API 通信

凭证不会被转发给任何第三方，也不会在服务端持久化。

使用说明

  1. 在「Refresh Token」「Client ID」中填入你自己邮箱账号的微软 OAuth2 凭证，Email 为选填，仅用于结果展示。
  2. 「平台类型」用于按关键词匹配对应平台的验证码邮件，选择 all 则不限平台。
  3. 点击「获取验证码」，系统会从最近 20 封邮件中查找并提取验证码。
  4. 点击「复制」按钮即可将验证码复制到剪贴板，用于登录验证。
